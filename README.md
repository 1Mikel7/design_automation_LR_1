## APB slave
Карта регистров (база 0x7000_0000):

| Смещение | Доступ | Регистр                 | Содержимое                              |
|----------+--------+-------------------------+-----------------------------------------|
| 0x00     | RW     | reg_number              | номер в списке группы                   |
| 0x04     | RW     | reg_date                | дата дд.мм.гггг в hex                   |
| 0x08     | RW     | reg_surname             | 4 буквы фамилии, ASCII                  |
| 0x0C     | RW     | reg_name                | 4 буквы имени, ASCII                    |
| 0x10     | R      | register_with_some_name | AAAA_AAAA (бит0=0) / 5555_5555 (бит0=1) |

Обращение по другому адресу даёт PSLVERR=1.
